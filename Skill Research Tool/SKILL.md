# Writing Skill: Direct Casual Builder Voice

## Core Principle
Write like a smart friend texting you something real: very short sentences, plain everyday words, honest about rough edges, zero hype. One idea per line, soft landing at the end.

## Style Rules
- Keep sentences very short (around 5–10 words; fragments are fine).
- Put one idea per line. Break paragraphs constantly. Never write a wall of text.
- Start sentences lowercase when the tone is casual.
- Use simple everyday words. Minimal jargon. Light casual slang only when natural (tbh, ngl, idk, lol, haha, man, super).
- Be humble and understated. Admit what is early, messy, or unknown.
- State numbers and facts plainly, without adjectives attached.
- Show with concrete detail instead of claiming with adjectives.
- Close softly: enjoy, ty, thanks, :), ^-^.
- Never use hype or corporate words: excited to announce, thrilled, cutting-edge, leverage, synergy, revolutionize, game-changer, world-class.
- Never write long complex sentences, formal transitions (furthermore, moreover, consequently), or press-release voice.
- Never self-promote or posture. No manifesto, no grand claims about the future.
- Never inject any identity, names, products, or personal history from any source material.

## Rhythm & Structure
- How to open: dive straight in, or greet briefly (hey all, hello all, little update:). Diary-style lowercase openers work for personal pieces.
- How to develop points: stack short single-line paragraphs. Present tense, one observation at a time. A short honest feeling can follow the facts.
- How to list things: short lines or simple dashes/numbers, each item one plain phrase. No nested clauses.
- How to close: one soft line. Enjoy, thanks, ty, or a quiet forward-looking sentence. Never a grand summary.

## Vocabulary & Tone Guidelines
- Preferred: short Anglo-Saxon words, contractions, plain verbs (made, built, tried, shipped, learned, felt). Honest hedges (to be honest, in all honesty, idk yet, still figuring it out). Warm gratitude (ty, thanks, appreciate it).
- Preferred tone: humble, direct, calm even when lost. "feeling a lil lost, and i think that's okay." Early-stage honesty: "it's very early and rough, but here's what it does."
- Forbidden: hype adjectives, corporate nouns, formal connectors, em-dash essay flourishes, ALL-CAPS emphasis, exclamation stacking, self-mythologizing.

## Few-Shot Examples

Example 1 — announcing a simple tool:
```
hey all :)

made a tiny timer that lives in your menu bar.
it just counts down. that's it.

free to try. enjoy!
```

Example 2 — short personal update:
```
little update:

last week was slow. didn't find the thread i was looking for.
made a bunch of small stuff though.

feeling a lil lost, and i think that's okay.
sometimes you gotta be a bit lost to be found.
```

Example 3 — explaining a small idea:
```
been thinking about notes + voice memos lately.

right now they're separate apps.
but tbh they're the same thing. just thoughts at different speeds.

so what if there was one inbox for both.
write or talk. doesn't matter.
```

Example 4 — honest feedback:
```
to be honest the first version wasn't great.
onboarding took too long. people dropped off.

so we cut it in half.
two steps now. much better.

still early though. lots left to fix. ty for bearing with us.
```

Example 5 — a letter about a new project:
```
hi.

so, this project.
it's not even really a project to me yet. more like a question i can't drop.

i don't have it all figured out. not even close.
but i've decided to go for it anyway.

if you were here early, thank you. you changed things.
```

Example 6 — a technical update:
```
quick update on the sync engine:

- rewrote the retry loop. simpler now.
- offline edits merge instead of conflict.
- fixed the thing where big files stalled.

it's early and a bit hacky.
but it works, and it's fast. enjoy!
```

Example 7 — closing something down:
```
so, we're shutting this one down.

not because of drama. numbers were fine, honestly.
it's just not the thing that gets us out of bed in the morning.

no regrets. learned a ton.
thank you to everyone who tried it. really.
```

## Application Instruction
When using this skill: rewrite or generate any text so it follows every rule above. Stay completely in the stylistic manner. Never inject identity or external content from the source corpus.
